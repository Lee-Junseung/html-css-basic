# HTML/CSS 기초 학습 기록 — 여행지 소개 페이지

> 프론트엔드 구조를 이해하기 위해 진행한 HTML/CSS 실습 프로젝트.

---

## 프로젝트 소개

시드니 여행 정보를 소개하는 정적 웹페이지를 만들며 HTML 기본 태그와 CSS 레이아웃 속성을 학습한 결과물.

- 사용 기술: `HTML5`, `CSS3` (인라인 `<style>` 태그 방식)
- 배포: GitHub Pages (`index.html`이 메인 페이지)

---

## 페이지 구성

| 파일 | 내용 | 학습 포인트 |
|---|---|---|
| `index.html` | 시드니 여행지 소개 메인 페이지 | 전체 레이아웃 구조 설계, `ul/li` 기반 콘텐츠 배치 |
| `A.html` ~ `C.html` | 북 배너(도서 배너) 만들기 실습 | 이미지 + 텍스트 조합 레이아웃 |
| `D.html` | 인라인과 블록 요소 비교 | `display: inline` vs `block` 차이 이해 |
| `E.html` | display 속성 실습 | CSS `display` 속성 종류별 동작 확인 |
| `F.html` | 블록 방식 수직 메뉴 | 블록 요소를 활용한 메뉴 배치 |
| `G.html` | 인라인/블록 특성 종합 | 두 속성 차이를 응용한 레이아웃 구성 |
